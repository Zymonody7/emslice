# 演示视频脚本（建议 4–5 分钟，录屏 + 旁白/字幕）

> 录制前：`conda activate emslice`；终端字号放大；提前生成 `data/bench`（`python bench/cases.py --out data/bench --N 33`）与公开矩阵（`bash bench/get_public.sh`），避免录屏中等待。

## 0. 开场（0:00–0:25）

画面：README 顶部 + 一句话标语。
旁白：
> 电磁谐振与微波器件仿真最终要解大规模非正定厄密矩阵的特征值问题。工程上最怕的不是慢，而是漏掉谐振模式。emslice 用惯性定理给每次求解出一张“没有漏解”的证书。

## 1. 问题与数据（0:25–0:55）

```bash
emslice info
emslice gen cube --N 33 --out data/demo/cube33.npz        # 10 万阶 PEC 立方腔
```
旁白：测试矩阵来自 Yee 网格旋度-旋度算子，均匀介质下有解析解；立方腔有大量 6 重、12 重简并模式，还有 3.2 万维梯度零空间——正好覆盖任务书中的重特征值和零附近密集谱。

## 2. 核心演示：重特征值 + 近奇异位移（0:55–2:00）

```bash
emslice solve data/bench/cube33.npz --sigma 3306.35929736182 -k 20 --out result/mid
python -c "import json;r=json.load(open('result/mid/report.json'));print(r['certificate']);print(*r['diagnostics'],sep='\n')"
```
画面重点（字幕标注）：
* 证书：窗口内惯性计数 = 已求得个数 → **证书通过**
* 诊断：σ 恰为谐振点（近奇异）→ 自动预偏移
* 后向误差 ~1e-11，与解析解误差 ~1e-16

对比（切到预先录好的 SLEPc 结果表）：同一算例 SLEPc 默认用法后向误差 0.12、漏 2 个简并模式。

## 3. 低频击穿：σ≈0 以上的物理模式（2:00–2:50）

```bash
emslice solve data/bench/cube33.npz --sigma 1e-3 --which above -k 20 --out result/low
```
字幕：
* 诊断“[目标重定位] 惯性括区 …”：自动避开 3.2 万重零空间
* 结果为前 20 个物理谐振模式（与解析解一致）
* 对比：SLEPc 按“取最近 3k 个再筛选”的常规做法返回 0 个有效结果

## 4. 复厄密（光子晶体）与公开矩阵（2:50–3:40）

```bash
emslice solve data/bench/bloch_rods33.npz --sigma 60 -k 16 --out result/pc    # 预先跑好，展示 report
emslice solve data/suitesparse/2cubes_sphere.npz --sigma 40 -k 20 --out result/pub
emslice check data/suitesparse/2cubes_sphere.npz result/pub
```
字幕：Bloch 周期边界 → 复厄密，实嵌入保持惯性可靠；SuiteSparse 公开电磁矩阵（谱跨度 1e9）证书通过，`check` 独立复核残差与正交性。
